# Guide — ASRP Media Documents Knowledge Hub

[English](README.md) · [Русский](README.ru.md) · [Front page](../README.md)

This guide describes a **catalog of 29 migrated media documents**. It is not a study: the repository contains no experiments, datasets or results, so these pages describe content, structure and the evidence status of what the articles say.

Every page has a Russian twin (`NAME.ru.md`). Numbers on these pages are computed from the repository by `tools/facts.py`; the generated diagrams come from `tools/build_visuals.py`; `tools/verify_no_loss.py` checks that nothing of the previous README or of any content file was lost.
