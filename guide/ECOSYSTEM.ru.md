## Патентные заявки из прежнего README

`metadata.yaml` говорит, что хаб «not itself the IP basis for any filing» (`patent_filing: none`). Далее прежний README перечисляет четыре программы с номерами заявок и ссылками на внешние репозитории. Это **номера заявок; заявка не является патентом**. В репозитории нет патентных документов и статуса подачи, он **не называет заявителей** и не говорит, кому принадлежит какая-либо заявка.
