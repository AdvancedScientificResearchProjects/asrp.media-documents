# Руководство — Хаб медиа-документов ASRP

[English](README.md) · [Русский](README.ru.md) · [Главная страница](../README.ru.md)

Это руководство описывает **каталог из 29 мигрированных медиа-документов**. Это не исследование: в репозитории нет экспериментов, данных и результатов, поэтому страницы описывают содержимое, структуру и статус доказательности того, что говорят статьи.

| | Страница | Читайте, когда нужно узнать |
|---|---|---|
| <img src="assets/icons/hub.svg" width="28" alt=""> | [HUB.ru.md](HUB.ru.md) | что это за хаб, откуда документы, что не вошло |
| <img src="assets/icons/topics.svg" width="28" alt=""> | [TOPICS.ru.md](TOPICS.ru.md) | какие есть темы, сколько документов в каждой, типы и статусы источника |
| <img src="assets/icons/navigation.svg" width="28" alt=""> | [NAVIGATION.ru.md](NAVIGATION.ru.md) | как устроены папки и как читать папку документа |
| <img src="assets/icons/evidence.svg" width="28" alt=""> | [CLAIMS.ru.md](CLAIMS.ru.md) | что показывает репозиторий и что заявляют статьи |
| <img src="assets/icons/ecosystem.svg" width="28" alt=""> | [ECOSYSTEM.ru.md](ECOSYSTEM.ru.md) | связанные репозитории, номера патентных заявок, контакты |
| <img src="assets/icons/open.svg" width="28" alt=""> | [OPEN-QUESTIONS.ru.md](OPEN-QUESTIONS.ru.md) | несостыковки и пробелы, найденные при чтении |
| <img src="assets/icons/figures.svg" width="28" alt=""> | [FIGURES.ru.md](FIGURES.ru.md) | все иллюстрации репозитория и руководства |

У каждой страницы есть английская пара (`NAME.md`). Числа на страницах посчитаны по репозиторию скриптом `tools/facts.py`; диаграммы строит `tools/build_visuals.py`; `tools/verify_no_loss.py` проверяет, что ничего из прежнего README и ни один файл содержимого не потеряны.
