# Открытые вопросы

[Руководство](README.ru.md) · [English](OPEN-QUESTIONS.md) · [Главная страница](../README.ru.md)

Несостыковки и пробелы, найденные при чтении. Исходные файлы не менялись.

1. **Классификация и видимость.** В `metadata.yaml` стоит `data_classification: INTERNAL`, в строке-паспорте прежнего README — «classification `INTERNAL`»; README говорит, что тексты статей **ПУБЛИЧНЫЕ**; репозиторий публичный. Что действует?
2. **Что значит `todo`?** У 25 из 29 записей `source_status: todo`, но у всех есть дата публикации, тексты на двух языках и `active: true`. Репозиторий статус не определяет.
3. **Нет файлов экспорта.** `metadata.yaml` называет три файла экспорта; в репозитории их нет (`.gitignore`), поэтому трассировку нельзя сверить с ними.
4. **Значение эпохи в `deleted_at`.** У всех 29 записей `deleted_at: '1969-12-31T23:00:00.000Z'` при `active: true`; вероятно, пустая дата, но это нигде не сказано.
5. **Повторяющиеся даты публикации.** У двух записей одинаковая `publication_date: '2023-03-10T07:25:06.805Z'`; 20 из 29 дат приходятся на 2023 год. Настоящие ли это даты, не сказано.
6. **Заявления без документов.** Заявления о патентах, товарном знаке и здоровье внутри статей не подтверждены документами ([CLAIMS.ru.md](CLAIMS.ru.md)); у патентных заявок из README нет статуса и названных заявителей.
7. **Варианты написания.** Одна и та же фамилия транслитерируется в текстах статей по-разному; правила написания в репозитории нет.
